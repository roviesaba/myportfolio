HOW TO VIEW
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html. It will open in your browser.
4. Internet is needed for the optional Google Fonts; the site itself works without them.

CONTACT FORM NOTE
This is a front-end demonstration. It validates the fields and opens the visitor's email application through mailto after you add your address. It does not store or send messages to a database/server.

HOW TO PUBLISH
You need a hosting service to make the site publicly accessible. One beginner-friendly option is GitHub Pages:
1. Sign in to GitHub and create a new public repository.
2. Upload index.html, style.css, and script.js to the repository's root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to provide your public website link.
6. Open that link in a private/incognito window to test it before recording.
